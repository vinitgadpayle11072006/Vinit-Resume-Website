VINIT GADPAYLE - BEGINNER RESUME WEBSITE

Files:
- index.html: Your resume website content.
- style.css: The CSS design and layout.

HOW TO PREVIEW:
1. Extract this ZIP file.
2. Keep index.html and style.css together in the same folder.
3. Double-click index.html to open the website in your browser.

HOW TO EDIT:
1. Open the folder in Visual Studio Code.
2. Open index.html to edit text.
3. Open style.css to change colours, spacing and layout.
4. Save your changes and refresh the browser.

HOW TO PUBLISH WITH GITHUB PAGES:
1. Create or open your GitHub repository.
2. Upload index.html and style.css to the main/root folder.
3. Go to Settings > Pages.
4. Under Build and deployment, choose Deploy from a branch.
5. Select the main branch and /(root), then Save.
6. Wait for publishing and copy the live website link shown there.

CHECK BEFORE SUBMITTING:
- Confirm that your details are correct.
- Add the live website URL and GitHub repository URL to the assignment PDF.
- Save the PDF using your roll number: RollNo_WD_MTProject.pdf.
